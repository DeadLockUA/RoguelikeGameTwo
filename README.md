# 99 экспериментов

Лаборатория инкрементальных рогаликов. Каждый эксперимент — отдельная небольшая игра, которая проверяет
одну необычную механику сборки (корабля, оружия, состава…). С каждым забегом игрок становится сильнее.

## Как запустить

Открой `index.html` в браузере, двойного клика достаточно. Сборка и сервер не нужны.

Если хочется через локальный сервер:

```bash
python3 -m http.server 8000
# затем http://localhost:8000
```

## Эксперименты

| № | Название | Статус | Суть |
|---|---|---|---|
| 01 | [Матрёшка](experiments/01-matryoshka/index.html) | играбельно | Снаряды — тоже корабли: оружие вкладывается в пули рекурсивно, прошлые забеги становятся модулями-окаменелостями. [Дизайн](docs/experiment-01-matryoshka.md) |
| 02 | Живой корабль | план | Сборка — семя клеточного автомата; корабль растёт и мутирует в бою. [План](docs/experiment-02-living-ship.md) |

## Структура

```
index.html                 — хаб: сетка из 99 экспериментов
css/common.css             — общий стиль
experiments/NN-name/       — отдельный эксперимент (свой index.html, js/, style.css)
docs/                      — дизайн-документы и планы
```

Прогресс каждого эксперимента хранится в `localStorage` браузера (`e99.expN`).
