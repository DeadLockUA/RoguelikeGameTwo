# 99 экспериментов

Лаборатория инкрементальных рогаликов. Каждый эксперимент — отдельная небольшая игра, которая проверяет
одну необычную механику сборки (корабля, оружия, состава…). С каждым забегом игрок становится сильнее.

## Как запустить

Онлайн: **https://deadlockua.github.io/RoguelikeGameTwo/** (обновляется автоматически при пуше).

Локально: открой `index.html` в браузере, двойного клика достаточно. Сборка и сервер не нужны.

Если хочется через локальный сервер:

```bash
python3 -m http.server 8000
# затем http://localhost:8000
```

## Эксперименты

| № | Название | Статус | Суть |
|---|---|---|---|
| 01 | [Матрёшка](experiments/01-matryoshka/index.html) | играбельно | Снаряды — тоже корабли: оружие вкладывается в пули рекурсивно, прошлые забеги становятся модулями-окаменелостями. [Дизайн](docs/experiment-01-matryoshka.md) |
| 02 | [Живой корабль](experiments/02-living-ship/index.html) | играбельно | Сборка — семя клеточного автомата; корабль растёт и мутирует в бою, пиковая форма сохраняется как штамм. [Дизайн](docs/experiment-02-living-ship.md) |
| 03 | [Оптический стол](experiments/03-optics/index.html) | играбельно | Один лазер + зеркала, призмы, линзы и фильтры: оружие — это траектория света. Реликвии переходят между забегами. [Дизайн](docs/experiment-03-optics.md) |
| 04 | [Секвенсор](experiments/04-sequencer/index.html) | играбельно | Оружие — музыкальный цикл: ноты стреляют, бьют и защищают; аккорды и ровный ритм усиливают. Прошлые забеги играют фоном как пластинки. [Дизайн](docs/experiment-04-sequencer.md) |

## Структура

```
index.html                 — хаб: сетка из 99 экспериментов
css/common.css             — общий стиль
css/experiment.css         — общие стили экранов (эксперименты 03+)
shared/arena.js            — общая арена: корабль, враги, волны, опыт, джойстик (эксперименты 03+)
shared/ui.js               — сохранения, навигация, карточки лаборатории (эксперименты 03+)
experiments/NN-name/       — отдельный эксперимент (свой index.html, js/, style.css)
docs/                      — дизайн-документы и планы
```

Прогресс каждого эксперимента хранится в `localStorage` браузера (`e99.expN`).
