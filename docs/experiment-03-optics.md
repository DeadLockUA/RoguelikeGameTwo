# Эксперимент 03 — «Оптический стол»

**Статус:** играбельный прототип · `experiments/03-optics/index.html`

## Ключевая идея

> Один лазер. Оружие — это траектория света, которую ты собрал.

Корабль — это оптический стол N×N. В левой клетке стоит лазер, он светит вправо (в нос корабля).
Игрок расставляет на столе зеркала, делители, призмы, линзы и фильтры. Каждый луч, вышедший за край
стола, становится лучом-оружием в мире. Корабль сам поворачивается носом к ближайшему врагу,
поэтому лучи «вперёд» бьют в цель, а отражённые назад и вбок прикрывают тыл и фланги.

Луч упирается в первого врага на пути (зелёный фильтр прожигает ещё двоих), поэтому против толпы
луч нужно делить, расширять и отражать. Это и есть главное решение при сборке.

## Элементы

| Элемент | Действие |
|---|---|
| Зеркало ⟋ | отражает (4 положения, нажатие — поворот); параллельный луч проходит |
| Делитель ⧄ | проходит + отражается, по 55% мощности |
| Линза ◎ | +60% мощности |
| Призма △ | веер из 3 лучей (прямо и ±45°), по 45% |
| Поворотник ↻ | поворот луча на 45° |
| Красный фильтр | горение 40% от мощности, 3 с |
| Синий фильтр | замедление 45% |
| Зелёный фильтр | пробивает ещё 2 врагов |
| Расширитель ⇕ | луч ×2 шире, −10% мощности |

Трассировка (`js/optics.js`): 8 направлений, отражение `d' = (2o − d) mod 8`, защита от петель
(посещённые пары клетка+направление+фильтры), бюджет 600 шагов, отсечка мощности < 0.5.

## Прогрессия

- **В забеге:** уровень → элемент из 3 (иногда «Накачка» +20% мощности) → расстановка на столе.
- **Реликвии:** в конце забега один использованный элемент можно сохранить; реликвии лежат в запасе
  в начале каждого забега (витрина 1 → 4).
- **Лаборатория** (фотоны): размер стола 5 → 9, мощность, дальность, гироскоп, корпус, двигатели,
  сборщик, стартовый набор, витрина; разблокировка 6 элементов.

## Идеи на потом

- Вращающиеся элементы в бою (зеркало, которое крутится само).
- Второй источник света, цветные источники.
- Враги-зеркала, отражающие лучи обратно.
