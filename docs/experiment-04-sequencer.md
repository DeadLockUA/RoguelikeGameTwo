# Эксперимент 04 — «Секвенсор»

**Статус:** играбельный прототип · `experiments/04-sequencer/index.html`

## Ключевая идея

> Оружие — это музыкальный цикл. Как ты сочинишь бит, так он и будет играть.

Сетка «дорожки × шаги» крутится сама в заданном темпе (по умолчанию 100 BPM, шаг — восьмая нота).
Каждая нота на текущем шаге срабатывает: звучит синтезированный звук (WebAudio, без файлов) и
происходит игровой эффект. Игрок только двигается, всё остальное делает музыка.

## Ноты

| Нота | Эффект |
|---|---|
| Бочка ◉ | ударная волна вокруг корабля, отброс |
| Малый барабан ✕ | выстрел в ближайшего врага |
| Хай-хэт ⋮ | три иглы веером |
| Пэд ◇ | заряд щита (до 3) + лечение |
| Бас ▼ | тяжёлая пробивающая сфера |
| Рывок ➤ | рывок с неуязвимостью, урон на пути |
| Хлопок ✺ | кольцо из 8 снарядов |
| Синт ∿ | цепная молния на 3 врагов |
| Акцент ! | модификатор: весь шаг ×1.8 |
| Эхо ↺ | модификатор: шаг повторяется на следующем с силой 50% |

## Синергии (`js/seq.js`)

- **Аккорд:** разные инструменты на одном шаге — +20% за каждый сверх первого.
- **Ровный ритм ♪:** ноты дорожки стоят через равные промежутки по кругу — дорожка +30%.
- **Полиритм:** дорожки пластинок имеют свою длину и крутятся независимо.

## Прогрессия

- **В забеге:** уровень → нота из 3 (иногда «Разгон» +8 BPM) → расстановка; кнопка «Прослушать»
  проигрывает цикл прямо в редакторе.
- **Пластинки:** в конце забега цикл записывается на пластинку. Выбранные пластинки играют фоном
  как дополнительные дорожки (сила 50% → 100%). С каждым забегом музыка (и огневая мощь) богаче.
- **Лаборатория** (винил): длина такта 8 → 16, дорожки 2 → 4, темп, корпус, двигатели, сборщик,
  стартовый набор, проигрыватель (1 → 3 пластинки), громкость пластинок; разблокировка 6 нот.

## Идеи на потом

- Тональность и аккорды по высоте (мажор/минор как разные эффекты).
- Враги, синхронизированные с ритмом (атакуют на сильную долю).
- Экспорт цикла как ссылки, чтобы делиться битом.
