# Эксперимент 01 — «Матрёшка»

**Статус:** играбельный прототип · `experiments/01-matryoshka/index.html`

## Ключевая идея

> Твои снаряды — тоже корабли.

Снаряд, который выпускает оружие, — это маленький корабль со своими слотами. В слот можно вставить
модификатор или **триггер**, а у триггера есть своя схема *вложенного* снаряда. Сборка — это дерево, а не
список: пуля → турель → осколки → искры → …

Мета-слой — **окаменелости**: в конце забега вся схема сжимается в один модуль, который можно вставить
в следующую сборку. Внутрь окаменелости может попасть другая окаменелость, и прошлые забеги копятся слоями.

## Игровой цикл

1. Забег — top-down арена, бесконечные волны по 30 с, босс каждые 5 волн.
2. Корабль стреляет сам (ЛКМ — ручной прицел), игрок только двигается.
3. Опыт → уровень → выбор 1 из 3 модулей → модуль попадает в запас → игрок ставит его в схему (E / Tab).
4. Смерть или «Завершить забег»: начисляются **образцы**, схема превращается в окаменелость.
5. Лаборатория: постоянные улучшения, разблокировка модулей, выбор окаменелостей в следующий забег.

## Модули

| Тип | Модуль | Эффект (на свой уровень) |
|---|---|---|
| модификатор | Усилитель ✚ | +40% урона |
| модификатор | Ускоритель » | +25% скорости |
| модификатор | Бронебой ⇥ | +1 пробитие |
| модификатор | Метроном ♪ | +25% частоты таймерных триггеров; на корабле — темп огня |
| модификатор | Расширитель ◯ | +35% размера |
| модификатор | Искатель ➶ | самонаведение |
| модификатор | Стабилизатор ∞ | +40% времени жизни |
| модификатор | Дубликатор ⧉ | +1 копия при каждом выпуске |
| триггер | Турель ◎ | каждые 0.35 с стреляет вложенным снарядом в ближайшего врага |
| триггер | Осколки ✸ | при исчезновении — 5 вложенных снарядов по кругу |
| триггер | Искра ϟ | при попадании — 2 вложенных снаряда в соседних врагов |
| триггер | Спутники ☉ | 2 вложенных снаряда кружат вокруг носителя |
| триггер | Минёр ⊕ | каждые 0.25 с оставляет неподвижный вложенный снаряд |
| особый | Окаменелость ◈ | каждые 1.4 с выпускает весь билд прошлого забега (ослабленный) |

Базовые параметры снаряда затухают с глубиной `d`: урон `10·0.62^d`, скорость `460·0.85^d`.
Глубокие снаряды слабее по отдельности, но их много.

## Ограничения (защита от экспоненты)

- **Глубина вложенности** — главный рычаг прогрессии: 1 → 4 через лабораторию.
- Слоты: корабль 2 → 6, вложенные снаряды 1 → 3.
- Глобальный бюджет: 2600 снарядов одновременно. При достижении лимита новые снаряды не создаются,
  в HUD появляется «(лимит)».
- Компиляция дерева обрезается на глубине 8 (на случай окаменелостей внутри окаменелостей).
- Окаменелости не расходуют лимит глубины, но слабее (50% → 100% через «Резонанс»).

## Мета-прогрессия (лаборатория)

Глубина, слоты корабля, слоты снарядов, корпус, двигатели, сборщик, анализатор опыта, стартовый набор,
хранилище окаменелостей (1 → 3), резонанс окаменелостей + разблокировка 7 модулей.

Образцы за забег: `убийства/4 + волна²·3 + боссы·25`.

## Архитектура кода

| Файл | Назначение |

## Что проверить в плейтесте / идеи на потом

- Ощущается ли разница между уровнями глубины? Нужен ли «вау» уже на первом забеге?
- Новые носители: луч, бумеранг, дрон с собственным ИИ.
- Триггеры-условия: «если на экране > 20 врагов», «каждый 3-й выстрел».
- Синергии по глубине: модуль, который сильнее, чем глубже он стоит.
- Визуализация «живого» дерева в HUD во время боя.
- Обмен окаменелостями между игроками (экспорт строкой).
